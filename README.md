# Java Small Projects ☕

This repository contains a collection of clean, object-oriented Java sub-projects developed to practice core programming principles, software design, and system architecture.

---

## 📂 Projects Directory

Here is a quick overview of the applications included in this repository:

* **[Academy System](./academy-system)**: A management system for educational academies, handling students, courses, and grading.
* **[Access Control](./access-control)**: A security-focused project implementing role-based access control (RBAC) and user authentication.
* **[Equipment Rental System](./equipment-rental-system)**: A system designed to manage inventory, tracking rented tools, return dates, and fees.
* **[Parking Permit System](./parking-permit-system)**: An application to manage vehicle parking spots, vehicle registration, and active permits.
* **[Smart Thermostat](./smart-thermostat)**: A simulation of an IoT smart home device regulating temperature and schedules.

---

## 🛠️ Tech Stack & Concepts
* **Language:** Java (JDK 11+)
* **Concepts:** Object-Oriented Programming (OOP), Encapsulation, Polymorphism, Exception Handling, and Clean Code practices.
* **Environment:** Linux / WSL (Ubuntu) with VS Code.
